# California Housing: прогноз стоимости жилья

Задача регрессии на датасете из 20 640 объектов. Цель - предсказать медианную стоимость жилья в районе Калифорнии по характеристикам района.

## Что сделано
- Загрузка и исследование данных, проверка пропусков
- Разделение на обучающую и тестовую выборки (80/20)
- Обучение двух моделей: линейная регрессия и Random Forest
- Сравнение по метрикам RMSE и R²
- Анализ важности признаков

## Результаты
| Модель | RMSE | R² |
|---|---|---|
| Линейная регрессия | 0.75 | 0.58 |
| Random Forest | 0.50 | 0.81 |

Ключевой фактор цены — средний доход жителей района (importance 0.52). Далее по значимости: количество жильцов на дом и географические координаты.

## Стек
Python, pandas, NumPy, scikit-learn, matplotlib
